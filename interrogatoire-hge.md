# Interrogatoire structuré HGE (Hépato-Gastro-Entérologie)

Pour une application de consultation HGE, il est conseillé de ne pas avoir simplement une liste
de symptômes : il faut un interrogatoire **semi-structuré**, avec des sous-champs qui apparaissent
selon le symptôme sélectionné.

## ⚙️ Structure idéale dans l'application

Symptôme → Oui/Non → sous-menu automatique → caractéristiques → durée → intensité →
signes associés → red flags.

Exemple :

```
Douleur abdominale ☑️
 ↳ Localisation
 ↳ Type
 ↳ Intensité EVA
 ↳ Début/durée
 ↳ Continue/intermittente
 ↳ Relation repas
 ↳ Irradiation
 ↳ Facteurs aggravants/soulageants
 ↳ Signes associés
 ↳ 🚨 Red flags
```

C'est beaucoup plus pratique qu'une fiche où tous les champs sont affichés en permanence.
